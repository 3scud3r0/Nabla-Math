# Registro de decisões

Decisões confirmadas: (1) Python local e dados versionados são a primeira entrega; (2) Lean prova enunciados sob hipóteses explícitas; (3) experimentos físicos exigem comparação empírica separada; (4) a rede pública não executa código não confiável por padrão. Pendências do mantenedor: licença do código, política de contribuição, propriedade de dados, domínio/organização do serviço, custos e moderadores. Cada decisão futura deve registrar data, alternativas, critérios, consequências e testes que a validam.
