# Registro de decisões

Decisões confirmadas: (1) Python local e dados versionados são a primeira entrega; (2) Lean prova enunciados sob hipóteses explícitas; (3) experimentos físicos exigem comparação empírica separada; (4) a rede pública não executa código não confiável por padrão; (5) o código está sob MIT, conforme `LICENSE`. Pendências do mantenedor: confirmar a política operacional de contribuições e dados, responsáveis/revisores, domínio/organização do serviço, orçamento e moderação. Cada decisão futura deve registrar data, alternativas, critérios, consequências e testes que a validam.
