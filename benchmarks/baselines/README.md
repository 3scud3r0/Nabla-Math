# Baselines

Cada baseline deve registrar versão do código, hardware, tempo, orçamento, divisão e
critério de verificação. Os números deste diretório são especificações: não há benchmark
científico publicado até que exista um dataset curado e execução reproduzível.

Métricas mínimas: taxa de reexecução, taxa de prova formal do enunciado correto, generalização
por família não vista, custo por registro, diversidade e taxa de retratação.
