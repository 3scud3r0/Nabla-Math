# Código de conduta

Discussões, revisões e contribuições devem tratar pessoas com respeito, criticar argumentos com evidências e documentar incertezas científicas. Assédio, ataques pessoais, publicação de informações privadas e falsificação de resultados não são aceitos. Para reportar conduta inadequada, use os meios de contato disponibilizados pelos mantenedores no GitHub; o projeto ainda precisa designar explicitamente responsáveis por moderação e tempos de resposta. Evite incluir dados pessoais em issues públicas.
