SEU LABORATÓRIO, SEUS DADOS

Calcule no seu computador.

A aplicação local oferece botões para executar cálculos racionais, iniciar e parar um loop limitado, explorar exemplos orbitais e de fluxo laminar, gerar LaTeX e exportar o banco. Compartilhar dados é uma escolha explícita.

Baixar instalador Windows ↗Guia de instalação ↗

O instalador fica disponível como artefato das execuções bem-sucedidas do workflow Windows; pode ser necessário acessar o GitHub para baixar. Em Linux e macOS, use o pacote Python.

UM REGISTRO QUE PODE SER AUDITADO

O caminho de cada resultado.

01

Formular

Escrever a expressão, as entradas e as condições de validade.

02

Transformar

Guardar cada regra aplicada e verificar o cálculo racional na entrada dada.

03

Preservar

Salvar o registro local, reexecutá-lo e gerar uma explicação em LaTeX.

04

Ampliar

Adicionar provas, modelos científicos e colaboração somente após testes próprios.
